# Industrial Fire Watch Requirements Matrix by Facility Type

## Overview

Industrial and high-risk facilities share a need for fire watch during impairments and hot work, but each facility type brings different hazards, stakeholders, and access rules. This matrix maps those differences so operations, EHS, and risk teams can scope coverage and evaluate the best fire watch companies near me against their specific site.

## Common Triggers Across All Facility Types

| Trigger | Typical References |
|---|---|
| Sprinkler impairment | NFPA 25, IFC 901.7, insurer impairment program |
| Fire alarm impairment | NFPA 72, IFC 901.7, insurer impairment program |
| Hot work | OSHA 1910.252, NFPA 51B, site permit |
| Construction or renovation | NFPA 241, IFC Chapter 33, OSHA 1926 |
| AHJ order | Local fire marshal |
| Shipyard / vessel work | OSHA 1915, NFPA 312, USCG rules |
| Military installation | UFC 3-601-02, base fire department |

Note: the AHJ, the insurer, and site owner rules can each add requirements. Confirm all three before scoping.

## Common Industrial Fire Watch Failures

- One guard assigned to an area too large to patrol on the required interval
- Guard not briefed on site hazards or PPE
- Insurer not notified of the impairment
- Hot work during shutdown without a dedicated watch
- Logs that satisfy the AHJ but not the insurer, or vice versa
